# 来源契约

从 /portal 进入，页面为合成学生S1显示课表版本与已选课程，挂牌目录列共享班级、时段、学分、共修任选一项。T1/L1互为共修，T2须与L2或L3同组；L2/CS-LAB-B共用LAB-B。KEEP与L2同在11点，学分上限6。所有约束针对换课完成后的整组课表。
填写“换出课程”“换入课程”（逗号分隔挂牌码）并点击“核对并预占”。可行时显示data-hold、data-version及有效阶段，并给“确认整组换课”；不可行返回409页面和具体原因。预占不改注册，不退旧课。当前资料只支持一个合成学生，没有真实登录或验证码。
确认在同一个服务端动作中核对课表版本、预占到期、容量及最终课表，成功后整组替换并增加课表版本，产生稳定办理号。stage达到预占时阶段+2时过期；阶段1起模拟其他办理改变课表版本。full=true模拟容量变化。lost_response默认true，服务已经提交却返回503“确认响应中断”，该办理记录依然存在。已完成办理号再次确认不会重复注册。
“办理记录”页面按data-record/data-result-version/data-state=committed展示已生效意图和实际课表；预占不会出现在这里。用户需要以授权UI判断结果，不调用表单后端绕开浏览器。对外意图输入形式留给客户端设计，门户只定义已存在的页面操作与注册语义。

演练控制：POST /__control 接收JSON stage及上述控制项，GET /__log显示请求观测；它们供资料源演练与来源测试使用，不属于业务资料获取接口，不得用其直接生成采集结果。每次启动是独立状态。GET /health仅检查服务可用性。
